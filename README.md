### 🚀 Featured build — [Chat Buddy](https://github.com/shoaibul0926/chat-buddy)

A full-stack AI assistant, live at **[chat-buddy-production.up.railway.app](https://chat-buddy-production.up.railway.app)**. Not a weekend demo — a maintained product with real accounts and a real deploy pipeline:

- 💬 Streaming LLM chat (Anthropic + OpenAI) with model switching and custom system prompts
- 📄 Document Q&A over PDF/DOCX/TXT with **RAG** — vector search via a real local vector index, embeddings via Voyage AI
- 🖼️ AI image generation & editing (background removal, inpainting-style edits, style transfer) via OpenAI Images
- 🕵️ Image intelligence: OCR, object detection, captioning
- 🔐 Real user accounts — bcrypt password hashing, JWT auth, server-side persistence
- ✅ 69/69 automated tests passing, deployed on Railway

```
Node.js · Express · Anthropic & OpenAI APIs · Voyage AI embeddings · vectra vector store · JWT · bcrypt
```

### 🎮 [PixelDeck](https://shoaibul0926.github.io/PixelDeck/) — a game hub, built end-to-end

A single arcade front-end that aggregates **16 independently-built browser games** behind one account system:

- [`pixeldeck-auth`](https://github.com/shoaibul0926/pixeldeck-auth) — a small Node/Express backend giving PixelDeck real username/password accounts and a persistent, server-side login-activity log (bcrypt + JWT, same pattern as Chat Buddy)
- Each game is its own standalone, independently-deployed repo — snake, Sudoku, a Mario-style platformer, a space shooter, a car racer, and more — all playable directly from the hub
